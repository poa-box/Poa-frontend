The first repairs, with a clear definition of done

  1. Correct controlled public website fields. GitHub organization, Poa-frontend, and the old Poa-site listing should direct current users to https://poa.box. Preserve historical project context where needed. Done: each public link lands on the intended canonical page and each live API field shows the correct URL.
  2. Consolidate old public references. If poa.community is still controlled, restore valid HTTPS before setting redirects to the corresponding poa.box pages. An HTTPS redirect cannot help users who cannot complete TLS. If control is gone, correct incoming references instead. For poa.earth, migrate the hardcoded gateway first, verify assets and a fresh deployment, then retire the white-label routing and authentication/CORS allowlists. Preserve Test6 context in old organization links where appropriate. Keep redirect routes only while the domain remains controlled.
  3. Confirm the homepage in Google's stored index. Inspect https://poa.box/ itself. Record indexing status, last crawl, and Google-selected canonical when available. A successful live test proves present accessibility, not index inclusion. If absent, investigate its actual reason and request indexing after a meaningful fix. Check Manual actions and Security issues once if absence is unexplained.
  4. Make the product's name explicit in visible copy. Keep the expressive headline. Improve the existing title and opening paragraph using the drafts below. This is clearer identity and result presentation, not a promise of a ranking lift.
  5. Reuse one organization identity in structured data. About currently redefines the same organization ID with a different logo, aliases, and social URLs. Reuse the homepage identity and align the About schema description with its visible, qualified ownership/cost wording. Keep Poa as the name and poa.box as a truthful alternate; the site already has this basic configuration.

  3. A reproducible agent example. Improve the existing integration guide with a tested example of joining a sandbox, completing an authorized task, and receiving contribution credit. Google emphasizes original, useful material and clear information about its creators; there is no minimum word-count target or guaranteed benefit from publishing more pages. People-first content guidance.

Measure the actual problem before judging a change

Use Search Console Performance → Search results → Web. Start with the last three months for context, then compare complete 28-day periods. Keep exact-brand, ambiguous-brand, and product-category queries separate. Break out countries and desktop/mobile where there is enough data; country is not a proxy for language, so retain relevant English queries from any country.

Suggested exact-brand query filter:

(?i)^(poa[ .-]?box|www\.poa\.box|perpetual organization architect)$

Track poa, poa org, poa organization, and category phrases separately. This regex is a starting segment, not an exhaustive definition of brand demand.

Work to avoid

Do not remove healthy redirects, repeatedly resubmit the same URL, manipulate sitemap dates, add keyword-stuffed pages, or buy backlinks. Do not migrate away from .box solely on the assumption that it is penalized. Google says it does not use meta-keywords, domain keywords have little effect by themselves, and generic top-level domain choice is not the obstacle suggested here. Google's SEO Starter Guide. Keep the stable sitemap; repeated indexing requests do not accelerate crawling.
